## Exploring Reinforcement Learning via Human Feedback under User Heterogeneity

**Reinforcement Learning from Human Feedback (RLHF)** is a leading approach for AI alignment, but makes a strong assumption regarding the homogeneity in human preferences. One of the ways (as proposed by [Park et. al.](https://arxiv.org/pdf/2405.00254) uses clustering to handle heterogeneity in user preferences, creating personalised reward models for different clusters. This repository has been created to test that claim.

### File Structure
- **HCI_Project_Report.pdf** - This is the document elaborating on the idea proposed. It is an official report with theoretical claims and empirical backing.
- **HCAI_CODE_FOLDER** - This folder contains the code files and instructions to run and re-create the code
- **Results** - This the folder containing all the visual results.
